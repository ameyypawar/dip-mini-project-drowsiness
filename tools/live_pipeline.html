What this does and does not show. Every stage above is the real operator from the project, reimplemented in JavaScript so it runs on live video. The openness reading is a simple geometric proxy — the vertical extent of the dark region — and is not the trained support vector machine, which runs in Python on 1,774 HOG and LBP features and scores 89.65% on held-out subjects. Use scripts/run_demo.py --source webcam for the real classifier.
