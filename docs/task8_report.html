Experiment Title Binary Morphological Processing – Erosion and Dilation
Aim To convert the segmented eye image of the previous week into a binary image at more than one threshold; to apply binary erosion and binary dilation with three structuring elements (3x3 square, 3x3 cross, 5x5 square) and study their effect on object size, boundaries, small noise, thin structures, gaps, broken objects and neighbouring objects; to compare the two operations; and to study how repeated application (1, 2 and 3 iterations) shrinks or grows and eventually removes or merges structures. Theory

Binary image and structuring element

A binary image is a set A ⊂ ℤ² of foreground pixel coordinates (here the dark pupil/iris/eyebrow pixels; background is the complement Ac). A structuring element (SE) B is a small set of offsets with a designated origin. Bz denotes B translated so its origin sits at pixel z, and the reflection is B̂ = {−b : b ∈ B}.

Erosion (fit)

A ⊖ B = { z : Bz ⊂ A } = ⋂b∈B A−b

A pixel z survives only if the SE centred at z fits entirely inside the object. Erosion shrinks objects, strips a layer of boundary pixels, deletes objects and protrusions narrower than the SE, and widens gaps between objects; it can also split an object joined by a thin neck.

Dilation (hit)

A ⊕ B = { z : B̂z ∩ A ≠ ∅ } = ⋃b∈B A+b

A pixel z is set if the (reflected) SE centred at z hits (overlaps) at least one object pixel. Dilation grows objects, thickens boundaries, closes narrow gaps and holes, joins broken pieces and merges nearby objects. Figure 2 shows both rules on a small shape.

Duality

(A ⊖ B)c = Ac ⊕ B̂   ⇔   A ⊖ B = (Ac ⊕ B̂)c

Eroding the foreground is the same as dilating the background with the reflected SE, and taking the complement. All three SEs here are symmetric so B̂ = B, but the code reflects anyway. The identity is verified pixel-for-pixel in Output (Table 10, Figure 17).

Structuring-element geometry

SE size and shape set how much and in which directions an object changes (Figure 1). The 3x3 square (9 pixels) is 8-connected: it changes an object by one pixel in all eight directions, so diagonal edges move faster (by √2) than axis-aligned ones. The 3x3 cross (5 pixels: centre + 4 neighbours) is 4-connected: it moves edges by one pixel orthogonally but only ~0.7 pixel along diagonals, so it is gentler and rounds corners into diamonds. The 5x5 square (25 pixels) is the Minkowski sum of two 3x3 squares, B5 = B3 ⊕ B3, so one 5x5 pass equals two 3x3 passes (confirmed pixel-identically for both operations on all 3 images). Iterating with the same SE n times equals one operation with the n-fold Minkowski sum: a growing square (or diamond for the cross).

Related composite operations (from src/morphology.py)

Opening = erosion then dilation (removes structures smaller than B); closing = dilation then erosion (bridges gaps smaller than B). They are used below as quantitative probes: |A| − |open(A)| counts “thin/small” pixels and |close(A)| − |A| counts bridgeable gap pixels.

Algorithm

A. Binary Conversion

  1. Read the test image (grayscale; convert with cvtColor only if it has 3 channels).
  2. Apply histogram equalization (Task 3) and upscale as in Tasks 3–7.
  3. Run seeded region growing (Task 7; auto seed, T = 45, 8-connected) to obtain the segmentation; form the segmented image S = enhanced pixel inside the region, 255 outside.
  4. Threshold: foreground = pixels of S with intensity < t (dark = object), for t ∈ {40, 60, 100}; display original / grayscale / binary and record counts.
  5. Select t = 60 as the working binary image for Steps B–D.

B. Erosion

  1. Build the SEs: 3x3 square, 3x3 cross (cv2.MORPH_CROSS), 5x5 square.
  2. For each SE compute A ⊖ B (one iteration).
  3. Record foreground count, area fraction, % change, connected components and boundary length; record thin-structure pixels |A| − |open(A)|.

C. Dilation

  1. For each SE compute A ⊕ B (one iteration).
  2. Record the same measures plus bridgeable-gap pixels |close(A)| − |A|.
  3. Compare erosion, dilation and their difference (morphological gradient).

D. Iteration Study and Duality

  1. Apply erosion and dilation for 1, 2 and 3 iterations with every SE; tabulate all measures.
  2. Keep eroding (up to 150 iterations) until the foreground is empty; record the vanishing iteration of the whole image and of each original component.
  3. Keep dilating; record the iteration at which the component count first drops (first merge) and the iteration at which a single component remains.
  4. Verify A ⊖ B = (Ac ⊕ B̂)c and its dual for every image, SE and iteration count, and verify OpenCV against an independent NumPy fit/hit implementation.

def to_binary(img, threshold, dark_foreground=True):
    if img.ndim == 3: img = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    m = (img < threshold) if dark_foreground else (img >= threshold)
    return m.astype(np.uint8) * 255

def make_se(shape, size):                      # 'square' or 'cross'
    return morph.structuring_element("rect" if shape == "square" else shape, size)

def erode(mask, se, iterations=1):  return cv2.erode(mask, se, iterations=iterations)
def dilate(mask, se, iterations=1): return cv2.dilate(mask, se, iterations=iterations)

def erode_ref(mask, se, iterations=1):         # A (-) B = AND of shifted copies
    a = mask > 0; ph, pw = se.shape[0]//2, se.shape[1]//2
    for _ in range(iterations):
        p = np.pad(a, ((ph, ph), (pw, pw)), constant_values=True)
        out = np.ones_like(a)
        for i, j in zip(*np.nonzero(se)):
            out &= p[i:i+a.shape[0], j:j+a.shape[1]]
        a = out
    return a.astype(np.uint8) * 255            # dilate_ref: OR of shifts, pad False

def n_components(mask):  return cv2.connectedComponents((mask > 0).astype(np.uint8), connectivity=8)[0] - 1

def boundary_length(mask):                     # fg pixels with a 4-neighbour background
    inner = cv2.erode(mask, cross3, borderType=cv2.BORDER_CONSTANT, borderValue=0)
    return int(((mask > 0) & (inner == 0)).sum())

def iterations_to_vanish(mask, se, max_iter=150):
    cur = mask
    for k in range(1, max_iter + 1):
        cur = cv2.erode(cur, se)
        if not cur.any(): return k

def merge_iterations(mask, se, max_iter=40):   # first drop in component count / single component
    n0 = n_components(mask); first = one = None; cur = mask
    for k in range(1, max_iter + 1):
        cur = cv2.dilate(cur, se); n = n_components(cur)
        if first is None and n < n0: first = k
        if n <= 1: one = k; break
    return {"n0": n0, "first_merge_iter": first, "single_iter": one}

def duality_check(mask, se, iterations=1):
    comp, se_r = 255 - mask, se[::-1, ::-1].copy()
    return int((erode(mask, se, iterations) != 255 - dilate(comp, se_r, iterations)).sum())

Comparison of Erosion and Dilation

Both operators use the same SE and are duals, but they act on opposite sets: erosion trims the object, dilation trims the background. The measured one-iteration changes (Figure 15, Tables 2–7) make the symmetry concrete:

The asymmetry between good/glasses (about ±6–7 % per iteration) and poor_lighting (about ±24 %) is a size effect: poor_lighting has a much smaller, more fragmented foreground (7160 px, 1417 boundary pixels) so the boundary layer removed or added is a far larger fraction of it. On the compact good/glasses objects (14 784 and 11 760 px, boundary 962 and 612) the same one-pixel shell is a few percent. A larger SE scales the effect: the 5x5 square changes area about twice as much as the 3x3 square per pass (good -13.7% vs -7.0%), being exactly two 3x3 passes. The cross is the gentlest (good -6.2%, +6.2%) because it does not move diagonal edges.

Erosion followed by dilation (opening) does not return the original: the pixels that stay lost are exactly the structures thinner than the SE (Table 9: up to 952 pixels on poor_lighting with the 5x5 square), and closing bridges gaps by up to 872 pixels. This is why the pair is used together in src/morphology.py’s clean_mask.

Effect of Iterations

Repeated erosion. Each iteration peels a one-pixel shell (3x3 square), so area falls roughly linearly in iterations for a compact object (Figure 16, top) and the object finally disappears. Measured area change after 1, 2, 3 iterations (3x3 square): good -7.0% / -13.7% / -20.2%; poor -23.6% / -39.3% / -51.7%; glasses -5.9% / -11.8% / -17.3%. With the 5x5 square poor_lighting loses -84.0% after only 3 iterations.

Which structures disappear. Structures vanish in order of width. On poor_lighting (3x3 square) 15 of the 17 original components (the speckle, areas 1–52 px) vanish at iteration 1 and one more at iteration 2; only the main eye/eyebrow object survives, and it sheds small pieces itself (8 components after iteration 1: a 5412-px body plus pieces of 4–20 px). By iteration 3 the body has split into 3 pieces (56, 1084 and 2316 px), the eyebrow band separating from the iris ring (Figure 7). On glasses_reflection the isolated 32-px glare dot vanishes at iteration 2 (3x3 square) or 3 (cross), and on good_lighting the 4-px speck vanishes at iteration 1. The last surviving structure is always the widest part of the pupil/iris region, which vanishes entirely at iteration 27 (good), 12 (poor), 29 (glasses) for the 3x3 square, 37 / 16 / 34 for the cross and 14 / 6 / 15 for the 5x5 square (Table 8). Vanishing time is about half the object’s smallest width divided by the SE radius, so the cross (which moves diagonal edges more slowly) lasts longest and the 5x5 square shortest. Erosion can also increase the component count by cutting a thin neck: good_lighting goes 2 → 1 → 1 → 2 (3x3 square) because the speck is removed first and the neck to a lower structure breaks at iteration 3.

Repeated dilation. Each iteration adds a one-pixel shell: area grows about +7.0%, +13.6%, +19.8% on good_lighting, but the growth of poor_lighting is far larger (+55.2% after 3 iterations; +89.3% with the 5x5 square) because gaps between fragments are being filled as well as the outline moving outward. The measured component counts fall while the boundary length falls (poor 1417 → 829): the outline becomes smoother.

Which regions merge. The first merge happens at iteration 1 with the 3x3 square, 3x3 cross (poor, good) and 5x5 square on every image; on glasses_reflection the cross needs 2 iterations (the 32-px dot lies diagonally off the main object, and the cross does not extend along diagonals). On poor_lighting the 17 components collapse as 5 (iteration 1) → 3 → 2 → 1 for the 3x3 square (single component at iteration 4), 6 → 3 → 2 → 2 → 1 for the cross (iteration 5) and 3 → 1 (iteration 2) for the 5x5 square. The speckle around the iris merges with the iris ring and eyebrow first (after 3 iterations of the 3x3 square only a 64-px fragment remains separate from the 11 052-px main body); the last merge absorbs that residual fragment. Beyond that point further dilation only inflates one merged blob (good_lighting: a single component from iteration 1, area +19.8% at 3 iterations and still growing).

Erosion and dilation are not inverses. Eroding then dilating with the same SE (opening) restores the large object’s shape but not deleted fragments; dilating then eroding (closing) keeps merged objects merged. Repeating either operation is therefore a controlled loss of information, which is the price of noise removal or gap bridging.

Observations
  1. All three source images are single-channel infrared, so the grayscale step changes nothing (verified: the panels are numerically identical).
  2. The binary image depends strongly on the threshold: for poor_lighting t = 40 / 60 / 100 give 8 / 17 / 1 components and 4528 / 7160 / 11 130 foreground pixels. Thresholds close to the equalized Otsu value (62–88) keep the iris texture as fragments; higher values fill it in.
  3. Erosion (3x3 square, 1 iteration) removed 5.9 – 23.6 % of foreground and dilation added 5.8 – 23.9 %; for every image the two are nearly equal and opposite (e.g. good −7.02 % / +6.97 %), differing slightly because of local concavities and image structure.
  4. Structuring-element order (least to most aggressive) is 3x3 cross < 3x3 square < 5x5 square for both operators on all 3 images, and the 5x5 square equals two 3x3-square iterations pixel-for-pixel.
  5. Erosion removes small noise: poor_lighting component count goes 17 → 8 (3x3 square, iteration 1) and the 32-px glare dot on glasses_reflection is gone by iteration 2.
  6. Dilation merges: poor_lighting reaches a single component at iteration 4 (3x3 square), 5 (cross), 2 (5x5).
  7. The complete foreground disappears under erosion at iteration 27 / 12 / 29 (3x3 square), 37 / 16 / 34 (cross) and 14 / 6 / 15 (5x5 square) for good / poor / glasses.
  8. Boundary length decreases under both operators (smoothing), so it is not a monotone indicator of object size: use area for size and components for noise/merging.
  9. The duality A⊖B = (Ac⊕B̂)c holds with 0 differing pixels in all 27 cases, for both directions, and OpenCV matches an independent set-definition implementation exactly.
  10. Region-grown segmentation at T = 45 includes the eyebrow and speckle around the iris (Task 7 “leakage”); erosion followed by dilation is the natural way to separate the iris from the eyebrow, and dilation/closing the natural way to unify the iris speckle – this is the practical link to the drowsiness pipeline.
Conclusion

Binary erosion and dilation were implemented in src/binary_morphology.py, reusing src/morphology.py for structuring elements and the Task 7 region-growing output (src/region_growing.py) as the segmented input, and evaluated on the same 3 dataset images with three thresholds (t = 40, 60, 100; t = 60 used for the experiments), three structuring elements and 1–3 iterations, all with measured pixel counts, component counts and boundary lengths. Erosion shrinks objects, removes noise and thin structures and can split objects; dilation grows objects, closes gaps and merges neighbours. Per iteration the 3x3 square changes area by about 6–24 %, the cross slightly less and the 5x5 square about twice as much; the effect is largest on the small, fragmented poor_lighting foreground. Repeated erosion eliminates the whole foreground after 6–37 iterations depending on image and SE, small fragments first and the iris/pupil body last; repeated dilation merges all fragments into one component within 1–5 iterations. The duality of the two operators was confirmed numerically (0 differing pixels in 27 cases), and an independent fit/hit implementation matched OpenCV exactly. For the drowsiness pipeline the useful operations are the composites: opening to remove speckle and detach the eyebrow, and closing to make the iris a single solid region before the eye-openness measurement.
